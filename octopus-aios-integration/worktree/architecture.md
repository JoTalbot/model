# Gemaxi: Personal Memory Operating System (OS)

Проект Gemaxi — это децентрализованная система «бессмертной» памяти, спроектированная так, чтобы ваши данные пережили централизованные платформы и физические носители.

## 🏗 Архитектурные Слои

### 1. Сетевой Слой (P2P Mesh)
- **Kademlia DHT**: Распределенная таблица для поиска узлов и ключей.
- **Gossip Protocol**: Эпидемическое распространение метаданных и задач. Обеспечивает синхронность состояния всей сети без центрального сервера.
- **RPC (MessagePack over TCP)**: Прямое взаимодействие между узлами для передачи тяжелых данных и выполнения команд.

### 2. Слой Памяти (Hierarchical Memory)
- **Hot Layer (Vector Memory)**: Векторное пространство (Embeddings) для мгновенного семантического поиска. Используется в RAG.
- **Warm Layer (Structured Graph)**: Репозиторий метаданных и семантических связей. Здесь живет граф знаний, объединяющий чаты, файлы и идеи.
- **Cold Layer (Immortal Storage)**: 
    - **IPFS**: Контентно-адресуемое распределенное хранилище.
    - **Arweave**: Постоянное хранение в блокчейне (оплата один раз — доступ навсегда).
    - **Encryption**: AES-256-GCM шифрование на стороне клиента.

### 3. Слой Интеллекта (Autonomous Agents)
- **Memory Linker**: Агент, который анализирует новые записи и автоматически прокладывает связи к старым воспоминаниям, формируя ассоциативную память.
- **Archivist**: Агент, принимающий решение о переносе критически важной информации в «вечное» хранилище.
- **Graph RAG**: Движок ответов, который использует не только векторы, но и графовые связи для получения максимально глубокого контекста.

### 4. Интерфейсный Слой (VFS & CLI)
- **Virtual File System (VFS)**: Пользователь работает с файлами через привычную иерархию папок, но за этим стоит семантическое облако.
- **Time Machine**: Возможность «отмотать» состояние памяти назад и увидеть мир глазами системы в любой момент прошлого.

## 🛠 Ключевые Технологии
- **CRDT (Conflict-free Replicated Data Types)**: Гарантирует, что данные на всех ваших устройствах синхронизируются без конфликтов, даже при работе оффлайн.
- **Reed-Solomon (Erasure Coding)**: Разбиение данных на осколки. Система восстанавливает информацию, даже если 30% узлов сети будут уничтожены.
- **OpenRouter & Local LLM**: Гибкий выбор моделей от Claude 3.5 до локальных Llama 3, работающих без интернета.

## 📈 Roadmap Развития
1. ✅ **Phase 1: Foundation.** P2P ядро, Kademlia, базовый RAG.
2. ✅ **Phase 2: Semantic VFS.** Переход от файлов к графу, запуск Linker и Archivist.
3. ✅ **Phase 3: Immortal Sync.** CRDT синхронизация, интеграция Arweave, шифрование.
4. 🚀 **Phase 4: Multi-modal & Personal App.** Интеграция с изображениями/голосом и полноценное Desktop/Mobile приложение (Tauri).
