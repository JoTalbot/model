### Назначение

octopus-dynamic-tools — это инструмент для автоматического настройка политик в Octopus. Он позволяет легко создавать и применять политики с учетом текущего состояния системы, что делает управление нагрузкой более эффективным.

### 3 bounded improvements without destructive actions:

1. **Улучшение безопасности**: Увеличение уровня безопасности для доступа к данным о политике.
2. **Улучшение производительности**: Повышение производительности путем уменьшения количества запросов к API Octopus.
3. **Улучшение удобства использования**: Создание более直观ного интерфейса для пользователей.

### Тест/метрику качества

Тест: Проверка правильной работы функции "POST /policy/evaluate" с использованием различных условий и действий.

Метрика качества: Количество успешных тестов в течение месяца.

### Риск и согласование

- **Риск**: Возможное увеличение нагрузки на Octopus API при внедрении новых политик.
  - **Согласование**: Нужно получить согласие от команды безопасности перед запуском
