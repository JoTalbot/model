### 1) Контекст конкретного назначения

Octopus Node Status Exporter (2026-05-18) — это лёгкий Prometheus exporter, который читает данные из двух файлов в директории `/var/lib/octopus/`. Эти файлы содержат информацию о состояниях нод и статусах по ним. Этот exporter собирает эту информацию, преобразует её в метрики и отправляет их на адрес `127.0.0.1:9717/metrics`.
