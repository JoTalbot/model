### 1. Контекст конкретного назначения

Octopus Node Status Exporter (2026-05-18) — это легкий Prometheus exporter, который читает следующие файлы из `/var/lib/octopus/` и отдает метрики на порту 127.0.0.1:9717/metrics:

- /var/lib/octopus/nodes.json — единый Node Registry
- /var/lib/octopus/watchdog-state.json — последний статус по нодам

Этот exporter позволяет легко собирать и отображать метрики о состоянии узлов Octopus, что особенно полезно для автоматической диагностики и управления.

### 2. Бounded улучшения без деструктивных действий

1. **Добавление поддержки новых типов метрик:**
   - Добавить поддержку нового типа метрики `octopus_node_health` для отображения состояния здоровья узла (ok, warning, critical).

2. **Улучшение логирования:**
   - Включить в exporter логирование ошибок и событий обработки данных.
