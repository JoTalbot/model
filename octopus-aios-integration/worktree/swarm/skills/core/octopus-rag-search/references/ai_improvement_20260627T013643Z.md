### Назначение

**octopus-rag-search**: Этот навык предназначен для обеспечения безопасного и краткосрочного доступа к актуальным данным о системе Octopus. Он использует технологию Ollama nomic-embed-text для получения реального эмбеддинга, который затем сравнивается с базовыми векторами Octopus. Если Ollama недоступен, он заменяется на нули.

### 3 bounded улучшения без деструктивных действий

1. **Бounded-ремонт**: В случае обнаружения ошибок или проблем с базовыми векторами Octopus, система автоматически попытается восстановить их, не нарушая стабильности системы.
2. **Бounded-обновление**: Если требуется изменение системы (например, добавление новых данных), это будет выполняться через консентс-гат, что гарантирует безопасность и согласованность процесса.
3. **Бounded-автоматизация**: Автономный агент будет автоматически выполнять bounded-шаги без необходимости вручную вызова команд.
