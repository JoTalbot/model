### Назначение

**Octopus Full MCP Guard** предназначен для обеспечения безопасности и надежности работы сервера Octopus с использованием MCP (Minecraft Server Protocol). Этот навык гарантирует полную безопасность, упрощает взаимодействие с Octopus-скриптами и позволяет легко использовать все доступные инструменты Octopus.

### 3 bounded улучшения без деструктивных действий

1. **Безопасное обновление MCP-сервера**:
   - Проверка текущего состояния MCP-сервера (PID, логи и здоровье).
   - Обнаружение и исправление возможных проблем с сервером.

2. **Пространство для Octopus-скриптов**:
   - Привязка всех доступных Octopus-инструментов, скриптов и навыков к MCP.
   - Управление доступом к Octopus-ресурсам через MCP.

3. **Соединение с CAS, Whisper, RAG, Swarm**:
   - Создание брандмауэра для этих инструментов.
