# 👻 Ghost Loader: Инструкция Бессмертия

Этот модуль предназначен для создания первого "неубиваемого" узла на удаленном сервере.

## Что он делает
1. **Docker Injection**: Устанавливает и настраивает Docker-контейнер с узлом Octopus.
2. **Tor Stealth**: Поднимает Hidden Service, позволяя управлять сервером через `.onion` адрес без открытых входящих портов.
3. **Persistence**: Регистрирует `systemd` службу, которая следит за состоянием узла и восстанавливает его после сбоев или перезагрузки.
4. **Auto-Update**: Позволяет узлу обновлять свой код из сети P2P или Git без участия пользователя.

## Как запустить на сервере
Нужен только один вход по SSH. Выполни:
```bash
sudo bash start_node.sh
```

## Управление
После запуска консоль выдаст `.onion` адрес. Открой его в **Tor Browser**.
В админке доступны:
- Редактор `config.yaml` (ключи TG, ИИ, настройки).
- Мониторинг P2P-соединений.
- Файловый менеджер загрузок.
- Журнал событий агентов.
