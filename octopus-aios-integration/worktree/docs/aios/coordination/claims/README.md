# Активные claims

Этот каталог содержит advisory-claims параллельных сессий. Формат и правила описаны в `../README.md`.

- Один активный claim = один отдельный Markdown-файл.
- Не редактируйте чужой claim.
- После завершения задачи удалите claim; итоговый контекст сохраните в `../sessions/<session-id>.md`.
- Отсутствие claim не означает, что worktree чист: всегда проверяйте `git status` и свежие журналы.

Сейчас в репозитории нет зарегистрированных активных claims на момент создания протокола. Незакоммиченная работа, существовавшая до внедрения протокола, перечислена в `../PROJECT_CONTEXT.md`.
