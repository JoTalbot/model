# Журналы рабочих сессий

Каждая машина, человек или ИИ-агент ведёт отдельный Markdown-файл по шаблону `../SESSION_TEMPLATE.md`.

Имена файлов:

```text
YYYYMMDDTHHMMSSZ-<machine>-<agent>-<short-task>.md
```

Правила:

1. Не переиспользовать журнал другой сессии.
2. Не переписывать исторические факты; исправления отмечать отдельной записью с UTC-временем.
3. Перед паузой, передачей или завершением обязательно заполнить раздел `Handoff`.
4. Не хранить секреты, PII и большие логи.
5. Журналы `DONE` сохраняются: они объясняют, где и почему работа закончилась.
