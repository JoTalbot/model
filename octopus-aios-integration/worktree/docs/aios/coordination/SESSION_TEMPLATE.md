# Шаблон журнала рабочей сессии

Скопируйте этот файл в `coordination/sessions/<session-id>.md`. Не используйте один журнал для нескольких параллельных агентов.

---
session_id: "YYYYMMDDTHHMMSSZ-machine-agent-task"
status: "ACTIVE"
agent: "название агента/человека"
machine: "hostname или устойчивый псевдоним"
started_utc: "YYYY-MM-DDTHH:MM:SSZ"
updated_utc: "YYYY-MM-DDTHH:MM:SSZ"
branch: "branch-name"
base_commit: "full-or-short-sha"
claim: "coordination/claims/<scope>--<session-id>.md или none"
---

перед стартом читают именно это поле активных журналов. Обновлять после каждого
существенного рубежа вместе с `updated_utc` во frontmatter.
