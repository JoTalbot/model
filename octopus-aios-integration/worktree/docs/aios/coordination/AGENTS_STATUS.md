# AIOS Agents Status Dashboard

Центральная точка видимости работы ИИ-агентов.

## Правила обновления

Каждый агент обязан обновлять этот файл при:
- начале новой задачи;
- смене этапа;
- обнаружении блокера;
- завершении работы.
