# Набросок / ТЗ: Google Drive + Contacts + Notion Automation

Дата: 2026-06-19
Источник: пользовательское ТЗ для нового модуля Octopus.

## Цель
Python-скрипт для полной автоматизации процесса мониторинга файлов на Google Диске и создания задач в Notion.

## Функционал
1. **Авторизация:** OAuth2 (`credentials.json` -> `token.json`) для Google Drive API и Google People API.
2. **Мониторинг:** Рекурсивно сканировать папку `1zAKjmh0Yh92SkJ-erYy4Xafhv19VY-yN` и все вложенные подпапки. Игнорировать папки (как контейнеры), обрабатывать аудиофайлы (mp3, m4a).
3. **Распознавание контактов:** Используя путь к файлу (название вложенной папки), сопоставлять имя папки или номер телефона с реальными контактами в Google People API. Если не найден — использовать имя папки как есть.
4. **Интеграция с Notion API:** Создавать карточку в базе данных:
   - Название: "Анализ разговора: [имя файла]"
   - Свойства: Contact, Status (автоматический выбор), Priority (скоринг по ключевым словам: "ВСП", "задержание", "адвокат" → "Критический"), Context, File.
5. **Кэширование:** `processed_files.json` для исключения повторной обработки.
6. **Автономность:** Инструкция по добавлению в планировщик (Windows Task Scheduler / Cron) каждые 15 минут.

## Технические требования
- Библиотеки: `google-auth`, `google-api-python-client`, `requests`.
- Модульный код, обработка ошибок API, логирование в консоль.
- Полный готовый код с комментариями + инструкция по получению OAuth-клиента в Google Cloud Console.
