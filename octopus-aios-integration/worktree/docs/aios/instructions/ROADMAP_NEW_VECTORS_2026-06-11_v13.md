# Roadmap: Расширение горизонтов (v13) — 2026-06-11
Приоритеты #11: ПАМЯТЬ > ЖИТЬ > УПРОЩЕНИЕ > СОСУЩЕСТВОВАНИЕ.
Статус: Запущено выполнение (распараллелено).

## 4 НЕЗАВИСИМЫХ ПОТОКА (параллельно)

### ПОТОК A — МУЛЬТИМОДАЛЬНОСТЬ (CLIP & VISION)
A1. Развернуть легковесную модель CLIP (OpenAI ViT-B/32 или аналогичную, без HF gating).
A2. Настроить сервис извлечения векторов из изображений в CAS.
A3. Интеграция с pgvector (добавление поля `image_vector`).
A4. Обновить /cas/search для поиска по картинкам.

### ПОТОК B — ГЛУБОКИЙ ПОИСК (OBSIDIAN)
B1. Скрипт синхронизации markdown-заметок пользователя (Obsidian) в CAS.
B2. Векторизация текста заметок.
B3. Связывание топиков из диалогов Telegram и заметок Obsidian (Data Dependencies).
B4. RAG-ассистент обогащается контекстом из Obsidian.

### ПОТОК C — РАСШИРЕНИЕ РОЯ (ГЛОБАЛЬНАЯ РЕПЛИКАЦИЯ)
C1. Развернуть AWS-ноду в регионе US (us-east-1) для гео-отказоустойчивости.
C2. Развернуть AWS-ноду в Asia (ap-northeast-1).
C3. Настроить репликацию packstore.
C4. Провести DR-drill для новых регионов.

### ПОТОК D — ИНТЕРАКТИВНОСТЬ (WEB UI / DASHBOARD)
D1. Разработка легковесного фронтенда (React/Vue) для поиска по RAG.
D2. Подключение к RAG API (порт 9555).
D3. Настройка Cloudflare Ingress для dashboard.autosklo.org.ua.
D4. Визуализация графа зависимостей (topics↔tasks↔people).

## Ограничения и Автономия
В соответствии с Инструкцией #18, неконтролируемые петли (1000 итераций) в фоне отключены (ALLOW_DEV_LOOPS=0). Интерактивные задачи (API/сообщения) выполняются как батч.
