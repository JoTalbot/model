# THIRD_PARTY_NODES — Интеграция сторонних узлов

## Типы узлов
1. **Parent (Hetzner):** Главная управляющая нода.
2. **Ubu-Worker (Home Server):** Мощный вычислительный узел (Whisper, Ollama).
3. **Child Nodes:** Локальные контейнеры/процессы на существующих серверах.
4. **Mesh Nodes:** Внешние бесплатные сервера (Oracle, Fly, AWS).

## Протокол подключения
1. Подготовка SSH-ключа (ED25519).
2. Настройка реверс-туннеля (если за NAT).
3. Установка Octopus Bootstrap.
4. Регистрация в `nodes.json`.
5. Включение в цикл `multisync`.
