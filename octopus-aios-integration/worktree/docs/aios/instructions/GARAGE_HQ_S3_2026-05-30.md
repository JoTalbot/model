# Инструкция: Garage HQ (S3 Object Storage)
Дата: 2026-05-30

## Обзор
Garage — это высокодоступное, распределенное S3-совместимое хранилище, написанное на Rust. 
В проекте Octopus оно используется для реализации вектора ПАМЯТЬ.

## Конфигурация
- **Бинарник**: /usr/local/bin/garage (v1.1.0)
- **Конфиг**: /etc/garage.toml
- **Данные**: /var/lib/garage/data (LMDB)
- **Метаданные**: /var/lib/garage/meta
- **Systemd сервис**: garage.service

## Порты
- **S3 API**: 3900
- **RPC (inter-node)**: 3901
- **Web (S3 static)**: 3902
- **Admin API**: 3903
- **Metrics**: 3909 (зарезервирован)

## Доступ (Octopus Key)
- **Key ID**: <S3_KEY_ID_REDACTED>
- **Secret**: <S3_SECRET_REDACTED>
- **Endpoint**: http://127.0.0.1:3900
- **Region**: garage

## Бакеты
- octopus-memory: основной бакет для хранения файлов системы.

## Команды
- garage status: проверка состояния кластера.
- garage layout show: просмотр топологии.
- garage key list: список ключей.
- garage bucket list: список бакетов.
