# THIRD PARTY NODES — Plan for External Contributions (2026-06-19)

## Onboarding Flow (consent gated)
1. Node operator fills consent form (human_consent + resource pledge)
2. Run third-party-node-guard skill
3. Health check + trust scoring
4. Onboard into global coordination hub
5. Reward via reputation / future marketplace

## Types of third-party nodes
- Free-tier volunteers (Oracle, Pi, VPS)
- Community contributors (skills, storage, compute)
- Research / hobby clusters

## Guardrails
- third-party-node-guard + trust scoring
- Graceful offboarding
- No privileged access without consent
- All traffic through P2P federation

## Marketplace angle
- Nodes can contribute storage/compute and earn "Octopus credits" (future)
