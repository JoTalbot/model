# FREE_TIER_INVENTORY — Реестр бесплатных ресурсов

## Облачные провайдеры
- **Oracle Cloud Always Free:** 4 ARM Ampere A1 (24GB RAM total), 2 x86 instances, 200GB Block Storage.
- **Fly.io:** 3 shared-cpu-1x (256MB RAM) apps, 3GB volume total.
- **Google Cloud (GCP):** e2-micro instance (US regions), 30GB HDD.
- **AWS Free Tier:** t2.micro/t3.micro (12 months), 30GB EBS, S3 5GB.
- **Hetzner:** (Только по купонам или явной команде, базово - платное).

## Платформы и инструменты
- **HuggingFace:** Хранение моделей и датасетов (Immortal CDN).
- **GitHub Actions:** 2000 min/mo для автоматизации и CI.
- **Nostr:** Децентрализованная шина данных и метаданных.
- **IPFS:** Децентрализованное хранилище (через бесплатные пиннинг-сервисы).
- **Tailscale/ZeroTier:** Бесплатные mesh-сети для связи нод.
