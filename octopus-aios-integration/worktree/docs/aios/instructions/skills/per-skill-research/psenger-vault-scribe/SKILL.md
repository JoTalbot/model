# Vault Scribe for Octopus
## Steps
1. Read input (transcript or JSON from /run/octopus or CAS)
2. Apply frontmatter (type: memory | person | eternal)
3. Use callouts, embeds, links
4. Write to packstore or /var/lib/octopus/obsidian/
5. Verify SHA
